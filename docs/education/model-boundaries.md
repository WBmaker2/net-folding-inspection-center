# 가상 접기 모형의 범위와 한계

## 이 모형이 다루는 것

전개도 포장 검수소는 면의 연결 관계를 살펴보는 기하 학습 도구입니다.

- 전개도에서 이웃한 면의 **인접 관계**와 공통 모서리를 확인합니다.
- 기준면에서 시작해 면을 어떤 순서와 방향으로 접는지 살펴봅니다.
- 접은 뒤 각 면의 최종 법선 방향과 서로 **맞은편**인 면을 비교합니다.
- 같은 자리를 차지하는 **겹침**과 채워지지 않은 방향을 찾아 원인을 설명합니다.
- 한 면을 한 칸 옮겨 연결 관계를 회복하는 수리 방법을 탐색합니다.

## 이 모형이 다루지 않는 것

이 결과는 실제 물건의 성능을 측정하거나 예측하지 않습니다. 종이의 두께와 휘어짐,
접착 탭, 재료의 강도, 제조 공정, 포장 상태나 포장 안전성을 다루지 않습니다.
따라서 이 모형의 접힘 결과로 실제 포장재의 내구성·제조 가능성·안전성을 판단할 수 없습니다.

## 3D 보기와 2D 권위

3D 보기는 계산된 관계를 눈으로 확인하기 위한 **시각화**일 뿐입니다. 판정의 권위는
렌더러와 독립된 순수 TypeScript 기하 계산에 있으며, 같은 계산을 2D 관계 표와 상태 문장으로
확인할 수 있습니다. WebGL을 사용할 수 없어도 2D 화면에서 같은 학습 목표를 수행할 수 있습니다.

교실에서는 화면 활동과 함께 실제 종이 전개도를 직접 오리고 접어 보시기를 권합니다.
손으로 접는 경험은 화면의 기하 모형이 다루지 않는 재료의 느낌과 차이를 발견하게 합니다.

## 학습 기록과 평가의 경계

이 앱은 순위, 속도, 타이머 또는 공식 점수를 제공하지 않습니다. 반복해서 예측하고
근거를 고쳐 보는 과정을 학습 증거로 삼습니다.

진행 저장은 사용자가 `이 탭에서 새로고침 후에도 진행 저장`을 선택한 경우에만 이 브라우저
탭의 `sessionStorage`에 기록됩니다. 탭을 닫으면 사라지며, 이름·학번·이메일 같은 개인정보를
수집하지 않습니다. 서버 전송, 로그인, 파일 업로드, 외부 AI도 사용하지 않습니다.

저장 키는 이전 버전과의 발견 가능성을 위해 `nfic.progress.v1`로 유지하지만 현재 payload
버전은 2입니다. 확인 가능한 이전 v1 진행은 구조화된 시도 맥락을 찾아 v2로 바꾸고, 모호하거나
오래된 기록은 안전하게 불러오지 않습니다.
