# Language Audit — Word and Sentence Expression

## Scope

이번 감사는 `elementary-webapp-ux-orchestrator`의 어린 학습자 언어 기준 중 새로 추가된 단어·문장 표현과 접기·근거 흐름의 표시 문구만 대상으로 합니다. 진단 정답, 수리 판정, 저장 형식, 전체 시각 디자인은 평가하지 않습니다.

정적 후보 인벤토리는 103개 파일에서 4,384개 문자열을 찾았으며, 테스트·e2e·내부 메시지를 포함한 triage 자료입니다. 아래 결정은 실제 렌더링 화면과 학습 의도를 함께 확인한 표시 문자열에만 적용했습니다.

## Reference contract

| 기준 | 확인 내용 | 결과 |
| --- | --- | --- |
| 학습 목표 연결 | 면·모서리·맞은편·겹침·접는 방향을 읽고, 접은 결과를 근거 문장으로 설명 | 유지 |
| 기존 앱 차별성 | 점수 대신 관찰·근거·재시도 안내 | 유지 |
| 용어 사전 | `면`, `모서리`, `맞은편`, `겹침`, `접는 방향`, `빈 면` | 유지 |
| 학습자 이름 | 화면에 `1번 면`처럼 표시하고 `F1`~`F6`은 표시하지 않음 | 질문/관계 문장 변환 유지 |
| 오류 안내 | 비난 없이 현재 문제와 다음 행동을 함께 말함 | 수리·저장 안내 구체화 |
| 문장 난이도 | 한 문장에 한 행동, 추상 명사보다 색·무늬·막대 등 구체 명사 사용 | 적용 |
| 개인정보·안전 | 이름·학번·이메일 입력 및 원격 전송 없음; 가상 접기 한계 고지 유지 | 유지 |

## Kept expressions

- `실제 종이의 두께·휘어짐·포장 강도·안전성을 보장하지 않습니다.`는 가상 모델과 실제 포장 안전을 구분하는 안전 문구이므로 유지합니다.
- `아직 접지 않음`, `아직 확인되지 않음`, `겹침 확인 필요`는 판정 전 상태를 숨기지 않는 정직한 상태 표현이므로 유지합니다.
- `기하 낱말`은 select 역할 이름과 도메인 용어에서 유지합니다. 빈 상태 안내만 더 짧게 하여 학습자 행동을 우선합니다.
- 미션 원본 JSON의 `F1`~`F6`은 내부 식별자로 유지합니다. `IntakeScreen`/`PredictionScreen`의 `formatFaceReferences`가 표시 시 `n번 면`으로 바꾸며, 이번 감사에서 콘텐츠 원본을 임의로 번역하지 않습니다.

## Excluded surfaces

- 테스트 파일의 설명 문장, e2e helper 문자열, 내부 예외 메시지
- 진단 선택지와 수리 판정 문구의 의미 변경
- 음성 출력, TTS, 녹음, VoiceOver 구현·검증
- 다크 모드, 새 이미지, 원격 데이터 수집, 저장 schema

## Acceptance

- 대상 표시 문자열에는 `F1`~`F6`이 나타나지 않습니다.
- `EvidenceSubmission.selectedTerms` 및 `completedSentence`의 정답 payload는 기존 도메인 테스트와 동일합니다.
- 모든 새 문구 테스트가 visible text와 accessible name을 동시에 확인합니다.
- 후보 재검색에서 미완성 자리표시자 표현이 계획·감사·보고 문서에 없습니다.
